## ✨ Funktioner

🗂️ &nbsp;**Profiler** — Skapa hur många namngivna tangentlayouter du vill. Växla med ett klick eller automatiskt när du ansluter till en server.

🔍 &nbsp;**Konfliktbläddrare** — Liveskanning av varje krockande bindning i din nuvarande layout. Fixa dem en och en eller i bulk. Vanilla-bindningar ändras aldrig utan att du ber om det.

🔄 &nbsp;**Auto-Switch** — Sätt regler som `hypixel.net → PvP` och Keyset byter profil i samma ögonblick som du ansluter. Fungerar med partiell matchning av serveradresser.

🔗 &nbsp;**Delningskoder** — Exportera vilken profil som helst som en kod på 8 tecken. Skicka den till en vän, klistra in den i Discord och importera den på några sekunder. Koder går ut efter 90 dagar. Inget konto behövs.

💾 &nbsp;**Spara live** — Gjort ändringar i vanilla Controls? Tryck på Spara live för att fånga exakt vad som är bundet just nu i den valda profilen.

🎓 &nbsp;**Interaktiv handledning** — Förstagångsguide som går igenom varje funktion med riktiga uppgifter. Starta den igen när som helst från knappen `?`.

🎨 &nbsp;**Polerat UI** — Eget tema med animationer, kontextuell nedtoning och en ren fliklayout. Inga extra bibliotek krävs.

---

## 🚀 Kom igång

1. Öppna **Controls** och klicka på **Keyset**.
2. Vid första start, följ den interaktiva handledningen; den tar ungefär två minuter.
3. Skapa en profil, klicka på **Spara live** för att fånga dina nuvarande bindningar och klicka sedan på **Aktivera**.
4. Öppna fliken **Konflikter** för att rensa överlappande tangenter.
5. Använd **Auto-Switch** för att sätta serverregler. Använd **Dela** för att exportera eller importera layouter.

## 🔒 Integritet

Profiler lagras **lokalt** i `config/keybindprofiles.json`. Keyset samlar inte in analysdata och skickar ingen telemetri.

Funktionen **Dela** laddar bara upp profildata till `share.beeboyd.com` när du uttryckligen klickar på **Dela**. Delade profiler är anonyma, lagras i 90 dagar och tas sedan bort automatiskt. Ingenting laddas upp utan din åtgärd.
