## ✨ 기능

🗂️ &nbsp;**프로필** — 원하는 만큼 이름 있는 키바인드 레이아웃을 만드세요. 클릭 한 번으로 전환하거나 서버 접속 시 자동으로 전환할 수 있습니다.

🔍 &nbsp;**충돌 브라우저** — 현재 레이아웃에서 충돌하는 모든 바인드를 실시간으로 스캔합니다. 하나씩 또는 일괄로 수정하세요. 바닐라 바인드는 사용자가 요청하지 않으면 절대 변경되지 않습니다.

🔄 &nbsp;**자동 전환** — `hypixel.net → PvP` 같은 규칙을 설정하면 연결하는 순간 Keyset이 프로필을 바꿉니다. 서버 주소 부분 일치도 지원합니다.

🔗 &nbsp;**공유 코드** — 어떤 프로필이든 8자 코드로 내보낼 수 있습니다. 친구에게 보내거나 Discord에 붙여 넣고 몇 초 만에 가져오세요. 코드는 90일 후 만료됩니다. 계정은 필요 없습니다.

💾 &nbsp;**라이브 저장** — 바닐라 조작 설정에서 변경했나요? 라이브 저장을 누르면 현재 실제로 지정된 내용을 선택한 프로필에 그대로 저장합니다.

🎓 &nbsp;**인터랙티브 튜토리얼** — 첫 실행 가이드가 실제 작업으로 모든 기능을 안내합니다. `?` 버튼에서 언제든 다시 실행할 수 있습니다.

🎨 &nbsp;**다듬어진 UI** — 사용자 지정 테마, 애니메이션, 상황별 어둡게 처리, 깔끔한 탭 레이아웃을 제공합니다. 추가 라이브러리는 필요 없습니다.

## 🚀 시작하기

1. **조작 설정**을 열고 **Keyset**을 클릭하세요.
2. 첫 실행에서는 인터랙티브 튜토리얼을 따라가세요. 약 2분 정도 걸립니다.
3. 프로필을 만들고 **라이브 저장**을 클릭해 현재 바인드를 저장한 뒤 **활성화**하세요.
4. **충돌** 탭을 열어 겹치는 키를 정리하세요.
5. **자동 전환**으로 서버 규칙을 설정하세요. **공유**로 레이아웃을 내보내거나 가져올 수 있습니다.

## 🔒 개인정보 보호

프로필은 `config/keybindprofiles.json`에 **로컬로** 저장됩니다. Keyset은 분석 데이터를 수집하지 않고 원격 측정을 보내지 않습니다.

**공유** 기능은 사용자가 명시적으로 **공유**를 클릭했을 때만 프로필 데이터를 `share.beeboyd.com`에 업로드합니다. 공유된 프로필은 익명으로 저장되며 90일 후 자동 삭제됩니다. 사용자의 행동 없이 업로드되는 것은 없습니다.
