## ✨ Recursos

🗂️ &nbsp;**Perfis** — Crie quantos layouts de teclas nomeados quiser. Alterne com um clique ou automaticamente ao entrar em um servidor.

🔍 &nbsp;**Navegador de conflitos** — Varredura ao vivo de todas as teclas em conflito no layout atual. Corrija uma por uma ou em massa. Teclas vanilla nunca são alteradas sem você pedir.

🔄 &nbsp;**Troca automática** — Defina regras como `hypixel.net → PvP` e o Keyset troca o perfil no momento em que você conecta. Funciona com correspondência parcial de endereço de servidor.

🔗 &nbsp;**Códigos de compartilhamento** — Exporte qualquer perfil como um código de 8 caracteres. Envie a um amigo, cole no Discord e importe em segundos. Os códigos expiram após 90 dias. Não precisa de conta.

💾 &nbsp;**Salvar ao vivo** — Fez mudanças nos Controles vanilla? Clique em Salvar ao vivo para capturar exatamente o que está atribuído agora no perfil selecionado.

🎓 &nbsp;**Tutorial interativo** — Guia de primeira execução que apresenta todos os recursos com tarefas reais. Abra novamente quando quiser pelo botão `?`.

🎨 &nbsp;**Interface polida** — Interface com tema próprio, animações, escurecimento contextual e layout limpo por abas. Nenhuma biblioteca adicional necessária.

---

## 🚀 Como começar

1. Abra **Controles** e clique em **Keyset**.
2. No primeiro uso, siga o tutorial interativo; leva cerca de dois minutos.
3. Crie um perfil, clique em **Salvar ao vivo** para capturar suas teclas atuais e depois em **Ativar**.
4. Abra a aba **Conflitos** para limpar teclas sobrepostas.
5. Use **Troca automática** para definir regras de servidor. Use **Compartilhar** para exportar ou importar layouts.

## 🔒 Privacidade

Os perfis são armazenados **localmente** em `config/keybindprofiles.json`. O Keyset não coleta análises nem envia telemetria.

O recurso **Compartilhar** envia os dados do seu perfil para `share.beeboyd.com` somente quando você clica explicitamente em **Compartilhar**. Perfis compartilhados são anônimos, ficam armazenados por 90 dias e são excluídos automaticamente. Nada é enviado sem sua ação.
