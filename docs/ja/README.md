## ✨ 機能

🗂️ &nbsp;**プロファイル** — 名前付きのキー設定レイアウトを好きなだけ作成できます。ワンクリック、またはサーバー参加時に自動で切り替えられます。

🔍 &nbsp;**コンフリクトブラウザ** — 現在のレイアウト内で衝突しているすべての設定をライブスキャンします。個別にも一括でも修正できます。バニラのキーは確認なしに変更されません。

🔄 &nbsp;**自動切り替え** — `hypixel.net → PvP` のようなルールを設定すると、接続した瞬間に Keyset がプロファイルを切り替えます。サーバーアドレスの部分一致に対応しています。

🔗 &nbsp;**共有コード** — 任意のプロファイルを 8 文字のコードとしてエクスポートできます。友達に送り、Discord に貼り付け、数秒でインポートできます。コードは 90 日後に期限切れになります。アカウントは不要です。

💾 &nbsp;**ライブ保存** — バニラのコントロールで変更しましたか？ライブ保存を押すと、現在実際に割り当てられている内容を選択中のプロファイルに保存します。

🎓 &nbsp;**インタラクティブチュートリアル** — 初回ガイドが実際のタスクで各機能を案内します。`?` ボタンからいつでも再起動できます。

🎨 &nbsp;**洗練された UI** — カスタムテーマ、アニメーション、状況に応じた暗転、整理されたタブレイアウトを備えた画面です。追加ライブラリは不要です。

---

## 🚀 はじめ方

1. **コントロール**を開き、**Keyset** をクリックします。
2. 初回起動時はインタラクティブチュートリアルに従います。約 2 分で終わります。
3. プロファイルを作成し、**ライブ保存**で現在のキー設定を保存してから **有効化**します。
4. **コンフリクト**タブを開き、重複したキーを整理します。
5. **自動切り替え**でサーバールールを設定します。**共有**でレイアウトをエクスポートまたはインポートできます。

## 🔒 プライバシー

プロファイルは `config/keybindprofiles.json` に**ローカル保存**されます。Keyset は分析データを収集せず、テレメトリも送信しません。

**共有**機能は、あなたが明示的に **共有** をクリックした場合にのみ、プロファイルデータを `share.beeboyd.com` にアップロードします。共有されたプロファイルは匿名で、90 日間保存された後に自動削除されます。あなたの操作なしにアップロードされることはありません。
