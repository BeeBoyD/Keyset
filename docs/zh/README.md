## ✨ 功能特性

🗂️ &nbsp;**配置文件** — 创建任意数量的命名按键布局。可以一键切换，也可以在加入服务器时自动切换。

🔍 &nbsp;**冲突浏览器** — 实时扫描当前布局中的所有冲突按键。逐个修复或批量修复都可以。未经你确认，原版按键绝不会被修改。

🔄 &nbsp;**自动切换** — 设置类似 `hypixel.net → PvP` 的规则，Keyset 会在你连接时立即切换配置。支持服务器地址的部分匹配。

🔗 &nbsp;**分享代码** — 将任意配置导出为 8 位代码。发给朋友，粘贴到 Discord，几秒内即可导入。代码 90 天后过期。不需要账号。

💾 &nbsp;**实时保存** — 在原版控制菜单中改了按键？点击实时保存，把当前实际绑定的按键捕获到所选配置中。

🎓 &nbsp;**交互式教程** — 首次运行指南会用真实任务带你了解每项功能。之后可随时通过 `?` 按钮重新打开。

🎨 &nbsp;**精致界面** — 自定义主题界面，带动画、上下文暗化和清晰的标签页布局。无需额外库。

---

## 🚀 快速开始

1. 打开**控制**界面，点击 **Keyset**。
2. 首次启动时跟随交互式教程；大约需要两分钟。
3. 创建配置，点击**实时保存**以捕获当前按键，然后点击**启用**。
4. 打开**冲突**标签页，清理重叠按键。
5. 使用**自动切换**设置服务器规则。使用**分享**导出或导入布局。

## 🔒 隐私

配置文件会**本地**存储在 `config/keybindprofiles.json`。Keyset 不收集分析数据，也不发送遥测。

只有当你明确点击**分享**时，**分享**功能才会把你的配置数据上传到 `share.beeboyd.com`。共享配置是匿名的，会保存 90 天并自动删除。没有你的操作，任何内容都不会上传。
