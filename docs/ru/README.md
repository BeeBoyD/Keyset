## ✨ Возможности

🗂️ &nbsp;**Профили** — Создавайте сколько угодно именованных раскладок клавиш. Переключайтесь одним кликом или автоматически при входе на сервер.

🔍 &nbsp;**Браузер конфликтов** — Живое сканирование всех конфликтующих назначений в текущей раскладке. Исправляйте их по одному или массово. Ванильные клавиши никогда не изменяются без вашего разрешения.

🔄 &nbsp;**Автопереключение** — Задайте правила вроде `hypixel.net → PvP`, и Keyset сменит профиль сразу после подключения. Работает с частичным совпадением адреса сервера.

🔗 &nbsp;**Коды обмена** — Экспортируйте любой профиль как 8-символьный код. Отправьте его другу, вставьте в Discord и импортируйте за секунды. Коды истекают через 90 дней. Аккаунт не нужен.

💾 &nbsp;**Сохранить Live** — Изменили что-то в ванильном меню управления? Нажмите Сохранить Live, чтобы записать в выбранный профиль ровно те назначения, которые активны сейчас.

🎓 &nbsp;**Интерактивное обучение** — Первый запуск проводит вас по всем функциям с настоящими заданиями. Запустить повторно можно в любой момент кнопкой `?`.

🎨 &nbsp;**Отполированный интерфейс** — Собственная тема, анимации, контекстное затемнение и аккуратные вкладки. Дополнительные библиотеки не требуются.

## 🚀 Начало работы

1. Откройте **Управление** и нажмите **Keyset**.
2. При первом запуске пройдите интерактивное обучение; это займет около двух минут.
3. Создайте профиль, нажмите **Сохранить Live**, чтобы сохранить текущие назначения, затем **Активировать**.
4. Откройте вкладку **Конфликты**, чтобы убрать пересекающиеся клавиши.
5. Используйте **Автопереключение**, чтобы задать правила серверов. Используйте **Поделиться**, чтобы экспортировать или импортировать раскладки.

## 🔒 Конфиденциальность

Профили хранятся **локально** в `config/keybindprofiles.json`. Keyset не собирает аналитику и не отправляет телеметрию.

Функция **Поделиться** загружает данные профиля на `share.beeboyd.com` только когда вы явно нажимаете **Поделиться**. Общие профили анонимны, хранятся 90 дней и автоматически удаляются. Без вашего действия ничего не загружается.
